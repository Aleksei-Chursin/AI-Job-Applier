## Overview
This skill provides proven navigation instructions, form filling patterns, and efficiency guidelines when applying to jobs on `myworkdayjobs.com`.

## Efficient Workflow & Instructions
1. Authentication: Always check credentials store first. Workday accounts are per-tenant (company specific). If no credentials match the exact company workday tenant, create a new account using profile credentials.
2. Multi-Step Form: Workday uses a multi-step wizard (My Experience -> Application Questions -> Voluntary Disclosures -> Review).
3. Resume Upload: Upload resume on the first page using upload_file. Wait 3s for auto-fill parsing.
4. Navigation: Fill required fields marked with red star (*). Click Save and Continue.
